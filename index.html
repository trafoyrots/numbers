📅 새 행에 기본으로 넣을 값
회 발행일을 넣으면 요일·회차가 자동 계산됩니다 · 각 행에서 개별 수정 가능
새 행 방식
새 용지 타 비워 두면 미기입 · 각 행에서도 바꿀 수 있음 (같은 용지 전체에 적용)
번호만 치면 됩니다. 두 자리를 치면 다음 칸으로 넘어가고(5~9는 한 자리로 바로 이동), 6번째 번호 뒤에는 다음 행이 자동으로 생깁니다. 1~4 한 자리는 01처럼 치거나 Space/Enter.
자·수·반: 번호 칸에서 A 자(자동) · S 수(수동) · D 반(반자동) (한/영 상관없음, 숫자패드 / * -) — 고른 방식은 다음 행에 이어지고, 칩을 눌러도 바뀝니다.
이동: ←→ 이전·다음 칸, ↑↓ 위·아래 행, 빈 칸에서 Backspace 이전 칸. 행(A~E)은 같은 회차 안에서 자동으로 매겨집니다.
✋ 반자동 직접 고른 번호: 번호 칸을 더블클릭하거나 칸 오른쪽 위 ✋를 누르면 연한 회색으로 표시됩니다. 입력하면서는 번호를 친 직후 F(숫자패드 .)를 누르면 방금 친 번호가 표시됩니다. 표시가 있으면 그 행은 자동으로 반자동이 되고, 저장·불러오기·인쇄에 그대로 남습니다.
붙여넣기: "자동 10 24 28 29 39 45" 같은 여러 줄 텍스트를 번호 칸에 붙여넣으면 한 번에 채워집니다. [12]처럼 대괄호로 감싼 번호는 직접 고른 번호로 표시됩니다.

② 로또용지 이미지에서 자동 인식

로또용지 사진을 선택하세요.
회차·발행일·요일 + A~E행(자동/수동, 번호)만 가져오고, 발행번호·바코드 숫자 등은 무시합니다.
끌어다 놓기나 Ctrl+V 붙여넣기(캡처 화면)도 됩니다. 이미지를 넣으면 용지 부분만 네모로 지정해 인식할 수 있습니다.

영상을 원하는 장면에서 멈춘 뒤 누르고, 공유 창에서 Chrome 탭 → 유튜브 탭을 고르세요. 화면 한 장만 찍고 공유는 바로 꺼집니다.
✂️ 용지 부분을 마우스나 손가락으로 끌어서 네모로 지정하세요. 지정하지 않으면 전체를 읽습니다.
이미지를 넣고 구역을 지정한 뒤 [선택 구역 인식]을 누르세요. (처음 한 번은 한글 인식 데이터를 내려받습니다)

노란 칸은 두 번 판독한 결과가 달랐던 칸, 점선 칩은 자동/수동을 확실히 읽지 못한 행입니다. 용지와 대조해 고친 뒤 입력칸에 추가하세요. 반자동 행은 여기서도 번호를 더블클릭해 직접 고른 번호를 표시할 수 있습니다.

📊 패턴 분석

로또 용지 단위(A~E 5행)로, 입력한 순서 그대로 패턴을 찾아 표시합니다. 행 순서를 바꾸거나 다른 용지의 번호를 섞지 않습니다. 용지 제목이나 행 글자를 누르면 입력 화면의 그 위치로 이동합니다. ✋ 표시는 반자동에서 직접 고른 번호입니다.

누른 번호는 빠지고, 남은 번호로 바로 동끝을 분석해 이 판과 아래 목록에 보여줍니다. 판의 ×숫자는 입력한 용지에서 동끝으로 묶인 횟수입니다. 다시 누르면 해제됩니다.
표시: 동끝 2개(앞·뒤) 동끝 3개 이상 연번 막대 사각 ³중복 횟수 한 용지 A~E 5행 · 같은 자리를 위에서 아래로 본 끝수가 1~2종류 바로 위·아래 행의 이웃한 2자리(2×2) · 연속 번호 4개로 채워지거나 하나가 모자라게 채워지면 사각형 표시 (연번은 가로·세로만, 대각선 연번은 인정 안 함)
